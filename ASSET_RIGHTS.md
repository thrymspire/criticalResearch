# Asset rights and publication boundary

© 2026 Thrymspire for the original synthesis/interface composition and original generated visualization/audio work, subject to any underlying rights in cited scholarship.

A public static HTML page cannot prevent visitors from copying client-delivered SVG, canvas pixels, JavaScript, or synthesized audio. This build therefore uses practical provenance rather than fake DRM: copyright notices, export marking, source separation, and a public build that does not include the private source archive.

Do not publish `brain.zip`, source PDFs, personal logs, location/mobility telemetry, or private filesystem paths with the public page.

## Export provenance
PNG graph/canvas exports receive a visible provenance mark. Generated WAV exports carry RIFF `LIST/INFO` fields (`INAM`, `IART`, `ICOP`, `ISFT`, `ICMT`) identifying Thrymspire and the build/key. These measures establish attribution evidence; they do not make client-delivered media impossible to copy.
