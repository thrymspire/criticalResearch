# Unified Critical Research — standalone build

## Public deployment
`index.html` is a small first-party GitHub Pages loader. It reconstructs the same-origin research payload, verifies the stored source payload, applies the current presentation cleanup, verifies the rendered artifact SHA-256 `44d239c1a727d58d80edf7cf9fcf147abc099f624ac6e34ac61fe4d3a4de382d`, and then starts the workstation.

The workstation has no framework, package-manager, CDN, analytics, or external runtime dependency.

## Local build
The local-only copy is a single HTML file that opens directly in a modern browser without a server or package installation.
